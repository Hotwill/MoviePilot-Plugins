# 媒体库云盘镜像（LibraryMirror）

入库整理完成后，把媒体库里的成品文件**按相同的目录结构**再复制一份到
OpenList/AList 等云盘存储，实现「本地一份、云盘一份」。

```text
媒体库  /media/电视剧/国产剧/兰香如故 (2026)/Season 01/兰香如故 - S01E01.mkv
云盘    /cloud/media/电视剧/国产剧/兰香如故 (2026)/Season 01/兰香如故 - S01E01.mkv
```

MoviePilot 原生一次整理只会落到一个媒体库目录（每条目录配置只有一个媒体库路径，
且选目录时只返回最佳匹配的一条），所以双写需要本插件补齐。

## 前置条件

1. 在 MoviePilot「存储」中配置好 OpenList/AList（类型 `alist` 或 `alistgo`）并测试连通。
2. 整理方式建议用 `copy` 或 `link`；用 `move` 时源文件会消失，但媒体库那份仍然能被镜像。
3. 插件读取的是**媒体库中的成品文件**，所以云盘上的命名与刮削结构和本地完全一致。

## 配置说明

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 启用插件 | 关 | 需同时填好云盘存储与云盘根目录才会真正启用 |
| 发送通知 / 成功也通知 | 关 | 默认只在失败时通知 |
| 云盘存储 | 空 | 从已配置的存储中选择，通常是 OpenList/AList |
| 云盘根目录 | 空 | 媒体库结构会原样挂在该目录下，例如 `/cloud/media` |
| 覆盖策略 | 大小不同才覆盖 | 可选「已存在则跳过」「总是覆盖」 |
| 复制同名刮削/字幕 | 开 | `.nfo`、`.srt`、`.ass` 等与媒体同名的文件 |
| 复制目录图片 | 关 | `poster.jpg`、`fanart.jpg`、`tvshow.nfo` 等目录级文件 |
| 跳过 STRM 文件 | 开 | STRM 指向直链，传到云盘没有意义 |
| 入库后延迟（秒） | 5 | 给刮削文件生成留出时间 |
| 失败重试次数 / 重试间隔 | 2 / 30 | 上传失败后的重试策略 |
| 定时补漏扫描 | 空 | Cron 表达式，如 `0 4 * * *`；留空不执行 |
| 单次最多处理 | 0 | 0 表示不限制，大库首次镜像建议先设小一点 |
| 文件间隔（秒） | 1 | 全量扫描时每个文件之间的等待时间 |
| 只镜像这些媒体类型 | 空 | 电影 / 电视剧，留空表示全部 |
| 只镜像这些二级分类 | 空 | 对应 MoviePilot 的媒体类别，如 `国产剧`，留空表示全部 |
| 媒体库根目录 | 空 | 留空自动读取「目录配置」里的媒体库目录，相对路径由此计算 |
| 镜像的媒体扩展名 | 常见视频格式 | 逗号或换行分隔 |
| 同名附属文件扩展名 | nfo/字幕/同名图片 | 逗号或换行分隔 |
| 立即运行一次 | 关 | 保存后立刻执行一次全量补漏 |

### 目录结构是怎么算出来的

插件把媒体库文件路径按**媒体库根目录**切掉前缀，剩下的相对路径原样接到云盘根目录后面：

```text
媒体库根目录     /media
媒体库文件       /media/电视剧/国产剧/兰香如故 (2026)/Season 01/兰香如故 - S01E01.mkv
相对路径         电视剧/国产剧/兰香如故 (2026)/Season 01/兰香如故 - S01E01.mkv
云盘根目录       /cloud/media
最终云盘路径     /cloud/media/电视剧/国产剧/兰香如故 (2026)/Season 01/兰香如故 - S01E01.mkv
```

配置了多个根目录时按**最长前缀**匹配。如果文件不在任何根目录下，插件会记一条失败历史
并提示检查配置，而不是猜一个路径。

## 触发方式

| 触发源 | 说明 |
| --- | --- |
| 整理入库事件 | 监听 `TransferComplete`，对新入库的媒体文件镜像 |
| 定时补漏扫描 | 遍历媒体库根目录，把云盘缺失或大小不一致的文件补齐 |
| 远程命令 | 交互消息发送 `/library_mirror` 立即执行一次补漏 |
| 插件 API | `POST /api/v1/plugin/LibraryMirror/mirror?apikey=<API_TOKEN>&path=<媒体库文件路径>` |

```bash
# 查询状态
curl "http://<MoviePilot>/api/v1/plugin/LibraryMirror/status" -H "Authorization: Bearer <token>"

# 外部触发某个文件的镜像
curl -X POST "http://<MoviePilot>/api/v1/plugin/LibraryMirror/mirror?apikey=<API_TOKEN>&path=/media/电影/片 (2026)/片.mkv"
```

## 常见问题

**云盘上没有文件，历史里写着「未匹配到媒体库根目录」**：媒体库根目录没配对。填 MoviePilot
容器内看到的媒体库路径（和「目录配置」里的媒体库目录一致），不是宿主机路径。

**一直显示跳过**：默认覆盖策略是「大小不同才覆盖」，云盘已有同样大小的文件就会跳过。
想强制重传改成「总是覆盖」。

**媒体库在网盘上（非本地）**：插件会先把文件下载到临时目录再上传，相当于中转，会占用
带宽和临时空间。这种场景更适合直接在两个网盘之间做同步。

**大库第一次镜像很慢**：先把「单次最多处理」设成 100 之类的小值，配合定时扫描分批上传。

## 注意

上传走的是 MoviePilot 的存储模块，速度和稳定性取决于 OpenList 后端与网盘本身；
大文件上传失败会按配置重试，失败记录可在插件详情页查看。
